# Codagram — engineering tracks, fees and admissions

Codagram's engineering tracks:

1. High-Performance Distributed Systems and Go: consensus protocols, Raft, Kafka internals, high-throughput microservices and orchestration. Prerequisites: basic programming and Linux fundamentals.

2. Autonomous Multi-Agent AI and LLM Systems: tool calling, multi-agent arbitration, RAG pipelines, low-latency streaming and latency optimisation. Stack: Gemini, TypeScript, Python, vector databases.

3. Resilient Production Full-Stack Infrastructure: React, TypeScript, Node or Go, Docker, Kubernetes, zero-downtime CI/CD. Architecture focus: multi-tenant, secure, high-concurrency systems.

4. Frontier Bio-Computing and Neural Interfaces: genomic sequencing pipelines and molecular visualisation.

Admissions and pricing: the registration fee is Rs 1,999 (₹1,999), a commitment fee that covers infrastructure and server slots. There is no large upfront tuition debt; the model is outcome-aligned, where students build real client and open-source proofs of work. Registration can be completed on the website by scanning a dynamic UPI QR code (Google Pay, PhonePe, Paytm).
